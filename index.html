Logs

📋 Что нужно в логе для VE calc
Обязательно:
  • RPM — обороты
  • MAP — давление во впуске (psi)
  • AFR actual — фактическая смесь с ШПЛ
  • AFR target — запрашиваемая смесь
Желательно для фильтрации мусора:
  • IAT — отсекать точки с завышенной температурой впуска
  • Coolant temp — отсекать прогрев
  • TPS — отсекать резкие переходные режимы
  • Knock retard / Total timing — отсекать точки с активной детонацией
