Logs

📋 Что нужно в логе для VE calc
Обязательно:
  • RPM — обороты
  • MAP — давление во впуске (psi)
  • AFR actual — фактическая смесь с ШПЛ
  • AFR target — запрашиваемая смесь
Желательно для фильтрации мусора:
  • IAT — отсекать точки с завышенной температурой впуска
  • Coolant temp — отсекать прогрев
  • TPS — отсекать резкие переходные режимы
  • Knock retard / Total timing — отсекать точки с активной детонацией

WOT Logs (CSV files)

📋 Требования к логу для MAF calc
Обязательные каналы:
  • CL/OL Fueling (status) — используются только строки со значением 10 (Open Loop)
  • Mass Airflow Sensor Voltage (V) — ось MAF таблицы
  • Primary Open Loop Map Enrichment (estimated AFR) — AFR target
  • Wideband AFR Gasoline — AFR measured, откалиброванный
Условия заезда: одна передача (обычно 3-я), WOT 100%, от низких оборотов до отсечки. Минимум 2 лога, лучше 3–5.
